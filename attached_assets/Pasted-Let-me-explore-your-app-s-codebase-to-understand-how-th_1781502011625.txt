### The Problem

When a user asks for **100 MCQs**, the AI (Gemini) may only return **40 unique ones** because:
1. A chapter may not have 100 distinct concepts
2. The AI token/response limit may cap the output
3. The API response is parsed and de-duped

### What You Need to Build

You need a **pre-check + confirmation dialog** before starting a test, in your test-generation frontend flow:

```
1. User selects "100 MCQ test"
   ↓
2. Frontend queries API for available unique questions
   ↓
3. If API returns fewer than requested (e.g. 40 < 100):
   → Show dialog: "Only 40 available. Cancel or Start Anyway?"
   ↓
4. User clicks "Start Anyway" → test starts with 40 questions
```
